# Linux System Monitoring Tool

## Project Overview
This project is a Linux-based system monitoring tool built with Python. It monitors CPU usage, memory usage, disk usage, and generates a system report.

## Purpose
The purpose of this project is to demonstrate Linux administration, Python scripting, automation, and system monitoring skills for an IT internship portfolio.

## Features
- Monitors CPU usage
- Monitors memory usage
- Monitors disk usage
- Displays system information
- Generates a system_report.txt log file
- Shows alerts when resource usage is high

## Technologies Used
- Linux Ubuntu
- Python 3
- psutil
- Bash terminal
- Git and GitHub
